# 最小 ISR 设计切片稿

**作者**：Alice（设计增量交付）。**日期**：2026-09-07。**状态**：设计建议，PM 落盘；不代表已实现或验证。
**证据口径**：同 BIT-FIRST-CLASS-INCREMENT.md（[U][C][S][SD][M][D][P]）。

## 1. 新裁定优先及保留／删除清单

本稿是中断设计 v2 的**削减切片**，不是完整安全模式换名。最小模式只承诺入口、上下文保存、返回和向量链接正确；**中断安全用户自保**。[U][D]

| 保留 | 删除／不实施 |
|---|---|
| B00 假接受封堵，随后接通真实属性语义 | 每槽 priority 配置与优先级管理 |
| MCS251 ISR 专属 CC、入口身份、注册记录 | A 线调用闭包检查、B 线全映像 SPX 检查 |
| 每次入场 37B 完整整数保存 | 静态槽闭包禁令的传递检查 |
| 独立 RETI lowering、正常出口统一恢复 | 最终机器栈上界摘要、嵌套链计算、M/K/W/R 安全门禁 |
| 槽 0–51 的向量布局／合法注册支持 | 安全摘要、优先级配置指纹、IP/IPH/IP2/IP3 初始化 |
| 合法未注册源的 fail-stop 默认入口 | 自动确认外设、自动开放源、运行时优先级便利接口 |
| ELF 对象身份、范围／重复／返回契约检查 | 以"缺安全摘要"为理由禁止普通库或跨 TU helper |

**删除安全检查，不删除 ABI 诚实性检查。** 错误 CC、错误返回帧、非法槽、未实现类型或机器指令仍硬错误。[U][D]

与旧文冲突明确：替换中断设计 v2 §7–§8 的 A/B/摘要/链式栈交付；替换 §9.4–§9.5 优先级配置认证（不要求用户提交 priority 或 M）；替换排期书 B09、B13（B10 只留入口与注册记录，B12 删 IP 初始化）；方言设计 §9.4 中断线负责闭包认证/摘要/栈预算的表述不再适用最小模式（EA 原态恢复等原语语义仍有效）。固定 bank 0/DPS 0、匹配硬件帧、排除 NMI 仍是**使用前提**而非重实施全程序检测。

**浮点边界记档**：`double`=32 位浮点（与 Keil C251 一致）[U]；浮点语义/运行库/参数/varargs 另案。当前目标头只设了浮点对齐，不能以此宣称 double32 已落实。[S]

## 2. 语法与 CC

### 2.1 属性主入口 `__attribute__((interrupt(N)))` [U][D]

- 恰一个整数常量表达式；截断前查非负、范围、槽合法性。N 是真实向量槽号（非优先级/使能位/字节地址）。
- ISR 签名 `void(void)`；拒绝参数、非 void 返回、变参、旧式带参定义。
- 首次声明建立 ISR 身份；重声明/定义须一致。
- 禁止普通调用 ISR、ISR 调 ISR、普通取址/强转逃逸、naked、always_inline、不兼容 CC；保活引用属编译器内部例外。
- 每 ISR 定义注册一槽；同 TU 尽早查重，跨对象 lld 查重。
- **本轮确认 `handleInterruptAttr` 仍缺 mcs251 分支落入 ARM 默认分发——MI0 必须先硬拒绝，不靠 attributes 警告维持假接受。**[S][D]

### 2.2 Keil 后缀别名（推荐纳入）

198 处语料全是 Keil 后缀；推荐可选方言模式支持 `void isr() interrupt N`，归约到同一 AST 属性/CC。[C][D]

- **不是单纯词法替换，普通宏无法无损完成**（对象宏包不进后续 token；函数宏要求 `interrupt(1)` 改变拼写）。
- 词法层提供受方言模式控制的 token，**由声明解析器**在函数声明符后解析 `interrupt`+受限常量表达式（数字/展开后数字宏/括号化常量）；Sema 只消费结构化属性。
- 后缀模式中 `void isr()` 空参数表规范化为零参 ISR 原型；不整体改变普通 C 旧式无原型规则。
- `using`/`__using` 继续拒绝（不能展开为空）；不承诺官方头文件/槽 13 中转/全部 Keil 方言。

### 2.3 专属 CC 与身份记录

`MCS251_INTR`、文本 `mcs251_intrcc`；当前命名 CC 到 127，**128 是候选非已分配号**。[S][D]

最小对象记录仅：协议版本、入口符号关联、IRQ 入口种类、硬件帧/保存 profile、槽号与必要能力。默认不可返回 IRQ 终止入口用独立种类。**不携带 A/B 安全结论、栈上界或 priority。**注册记录非 ALLOC；符号关联走专用元数据路线；不在 `.mcs251.attributes` 放 relocation；不复用函数指针 relocation 伪装 ISR 可取址。

## 3. 每层保存与 RETI

| 保存对象 | 字节 |
|---|---:|
| DR0、DR4、DR8、DR12 | 16 |
| DR16、DR20、DR24、DR28 | 16 |
| 当前选中的 DPX／DR56 | 4 |
| PSW | 1 |
| **软件保存合计** | **37** |

- A/B/WR/DPL/DPH 别名不重复计数；机器 Uses/Defs 准确建模。
- 硬件帧 profile=4B（含 PC/PSW1）；手册未补齐硬件证明，不得改标"手册已验"。[D][P]
- SPX 不直接 push/pop，靠平衡栈操作恢复；先保存 PSW 及未破坏现场再建局部帧；尾声逆序恢复，最后恢复 PSW 并 RETI。
- 每层保存**直接被打断层的实际状态**（含下层序言/尾声中途混合状态）；不要求整个序言关中断。
- 不做按需删减/shrink-wrapping/尾跳 helper；所有正常出口经本层恢复和 RETI。
- RETI 为独立指令/返回节点，表达硬件帧、SPX、PSW1 及结束当前服务层级副作用；不是 ERET 打印变体。
- ISR 可调用已有 ABI 支持的普通函数（含跨 TU helper）；helper 用普通调用/返回契约，不传播 ISR CC；后端本就不支持的签名仍拒绝；本切片不分析其重入安全。[D][U]
- **成本提示而非安全证明**：每层至少 `4+37=41B`，局部帧/spill/调用返回帧另计；链接器不据此算全工程最大栈。

## 4. 向量范围、跳空槽与 13 号陷阱

### 4.1 0–51 最小切片

向量公式 `0xFF0003 + 8N`。槽 0–6 有效、7 留空；0–51 内另有 13–15、22–23、31–35、45–46 等非普通注册位置。[M: PDF 674-676/印刷 634-636；槽 13-15 身份 PDF 147/印刷 107]

| 范围 | 布局字节 | 向量区 |
|---|---:|---|
| 0–51（已批准最小范围） | 416B | `[0xFF0003, 0xFF01A3)` |
| 0–64（战役推荐扩展） | 520B | `[0xFF0003, 0xFF020B)` |

每槽 8B；有效已注册源 4B EJMP+填充；合法未注册源 EJMP 至默认入口。**保留位置≠未注册合法源**：跳空槽不可注册、不可压缩、不可塞 BOOT/普通代码；13 中转、14/15 系统内部位置不自动填用户 fail-stop 或普通 ISR；保留地址占位、默认不输出未授权执行载荷。[D]

号码支持与实际板源可用性分开（12K128 Px 口边沿禁用警告不扩成 INT0/INT1 禁用）。[M: PDF 725]

### 4.2 为什么推荐战役扩至 0–64

**源码字面值最大 51，不等于移植真实槽最大 51。**[C][M] 抽读全部 21 处 `interrupt 13`：内容含 RTC、ADC DMA、M2M DMA、SPI DMA、UART1–4 收发 DMA、LCM/LCM DMA、I2C 收发 DMA、多源公共分发器。手册真实槽：UART2–4 DMA=52–57、LCM DMA/LCM=58/59、I2C DMA=60/61。[M: PDF 676/印刷 636]

建议：①本次执行范围保持 0–51（不擅自升级用户裁定）；②协议载体首版即可表达 64（避免改编号字段）；③面向全部例程的默认生产 profile **推荐另行批准扩至 0–64**（新增布局仅 104B，不连带实现优先级管理或外设模型）；④旧 `interrupt 13` 必须迁移（单源改真实槽；多源拆对应硬件 ISR 可复用普通 helper；不能普通调用 ISR、不能把 13 全映一个源）；⑤未批准扩展前涉及 52–61 的例程如实列为阻塞。

### 4.3 BOOT 冲突

当前资产 BOOT=`0xFF0100`，**0–51 已与之冲突**（非只有全表才冲突）。[S][D] 推荐新 IRQ CRT 将 BOOT 移至 `0xFF0210` 或布局约束计算更后位置，为全表预留升级空间；CSEG 随实际 BOOT 重布局。reset 区严格 `[0xFF0000,0xFF0003)` 只容 3B LJMP/跳板，不能放 4B EJMP。

## 5. E3 接口与极简 IRQ CRT

**E3 唯一向量所有者**[D]：①读取 v2 能力与入口/注册记录；②符号解析后查槽唯一性/合法性/目标精确入口身份/硬件帧 profile；③ROM 布局前合成唯一向量区与默认入口引用；④参与范围/ROM 重叠/重定位/未定义符号检查；拒绝旧 CRT VECS 并存；⑤map 展示"槽→地址→ISR/默认/保留"，**不输出伪造的 ISR-safe/栈安全结论**。当前接入点 `resolveSymbols → layout → errorUndefined → applyRelocations`，需增受控非 ALLOC 元数据解析与向量合成步骤。[S]

**不把 GC 绑成前置**：当前无 GC 保留所有输入代码即可；IR 端注册须成真正保活根（防 GlobalDCE 丢失）；未支持的 GC/LTO 明确拒绝；archive 懒提取/ICF/通用 AsmParser 不顺带实施。

**极简 IRQ CRT**[D]：新建独立 ELF IRQ 启动资产（不改历史 CRT、不内置旧八槽表）；只认证已知 reset 入口；普通中断关闭、NMI 未启用前提下建 bank 0/DPS 0、栈、全局及 bit 初值，再进 main。**不初始化 IP/IPH/IP2/IP3、不配优先级、不自动开放任何源或 EA、不统一清外设标志。**默认入口=独立不可返回 IRQ 终止身份：不调 C、不额外用软件栈、尽早清 EA 后永久停止；不执行 RETI、不打印、不插排空 NOP(4)。默认入口仍消耗硬件入场帧、清 EA 前可能被更高源打断；"零软件增栈"≠"零栈"或"原子停机"。不凭符号名或 noreturn 获身份豁免。

## 6. 用户契约——中断安全用户自保

**工具链承诺**[U][D]：属性不被忽略成普通函数；支持 profile 内每层保存/恢复正确、普通返回与 RETI 不混用；向量地址/合法注册/重复冲突/默认入口/布局正确；后端生成的固定帧/保存序列自身正确性（不以"用户自保"放过后端错码）；支持的 volatile/L1 位操作按明确语义发射。

**转移给用户的责任**[U][D]：

| 用户责任 | 工具链不承诺 |
|---|---|
| 选择/配置/运行时改优先级与使能 | 不建抢占图、不查过渡状态、不验最大嵌套深度 |
| 提供足够且始终有效的物理栈 | 不算最坏栈、不设 ISR headroom 门禁 |
| 审计普通函数/运行库/静态槽/overlay 异步重入 | 不实施 A 线；ISR 内才关中断修复不了下层已写坏的参数槽 |
| 避免受理窗口内不安全动态/手工 SPX 更新 | 不实施 B 线；未知安全性不标"已认证" |
| 维持 bank 0、DPS 0、匹配帧 profile、排除 NMI/T0 mode3 | 37B 不覆盖额外 bank、其他 DPTR、外设/加速器状态 |
| 声明共享变量可见性并设计同步协议 | volatile 不保证 RMW/多字节事务原子 |
| 正确确认外设/中断源/DMA/USB/FPU 共享资源 | 不自动清标志、不保存外设事务、不证运行库重入 |
| 保证最终从 ISR 正常出口返回 | 不允许 longjmp/手写 RETI/伪造返回帧；不证时限/无饥饿/无死锁 |

**时序用户须知**：关 EA/写中断寄存器可能立即截断受理；官方 `TR0=0; NOP(4); EA=0` 是保留响应机会范式 [M: PDF 724/印刷 684 图版亲核]；**NOP(4) 不是每次写后必插、不是排空证明、不是 SPX 原子提交、不是两写原子证明，最小编译器不自动插**；临界区恢复原 EA 不照抄无条件 EA=1；连续特殊指令链式顺延见手册 A.3，QEMU 不提供硬件精确时序证明；T0 mode3 不可屏蔽不能靠清 EA 补救。

## 7. 实施批次、验收与风险

| 批次 | 内容 | 体量 |
|---|---|---|
| MI0 | B00 假接受硬封堵 | S |
| MI1 | CC 128 查重登记；最小入口/注册/默认身份协议；数值槽拓扑 | M |
| MI2 | 属性 Sema、Keil 别名、AST/IR CC、使用限制与保活 | L |
| MI3 | 独立 RETI、37B 保存、别名效果、固定帧及正常出口 | L |
| MI4 | E3 v2 窄协议、唯一向量表、保留槽/冲突检查 | L（已有 v2 底座不重复计费） |
| MI5 | 新 IRQ CRT、BOOT 迁移、默认终止入口、初始化接线 | M |
| MI6 | C→ELF 端到端、模型保存窗口及分板真机验收 | L |

**不排 B09/B13/完整摘要，不沿用原 70–125 人日总包**。主要风险=保存指令/别名、硬件帧证据、v2 对象落点、向量区挤占 BOOT。

最低测试集：Sema（两拼写等价/宏槽号/`void f()` 兼容/坏签名/双参/溢出/冲突/普通调用/取址/using 拒绝）；IR（文本/bitcode 往返、CC 与槽号成对、O0-Os 不丢根不改普通 CC）；后端（37B 全集、PSW/DPX/DR 别名、早返回、spill、helper 普通返回、无尾跳、普通 ERET 不回归）；lld（槽 0/6/8/24/36/49-51 正例；槽 7/13-15 拒绝；52/64 在最小 profile 拒绝；重复/错身份/旧 VECS/BOOT 冲突拒绝；合法默认入口）；运行（单层及受控两层、保存前/中/恢复中/RETI 前窗口、逐层 SPX/PC/PSW1/整数哨兵恢复、共享 bit 不回滚、长期无漂移、默认终止）；QEMU 可触发覆盖与高槽静态布局分开；真机分板记账。
