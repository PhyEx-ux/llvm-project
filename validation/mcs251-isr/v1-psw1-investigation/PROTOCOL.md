# V1 输出协议与判读表（实板执行后回传用）

所有数值为十六进制。三张镜像共用同一串口协议（24MHz / 115200 / 8N1，P3.0/P3.1）：

- 发送 `g`（0x67）：跑满矩阵并逐行打印。
- 发送 `r`（0x72）：把 L 阶段（T10 同形 DJNZ 等待）连跑 128 次，打印 af-PSW1 取值分布。
- 发送 `q`（0x71）：从重复报告中退回 READY。

## 0. 判读基准：两视图共享物理标志的模型语义（2026-09-10 第二轮修订，第三轮补强 DJNZ 双分支基准）

本表全部预期值按模型语义推导（qemu 模型 `cpu.c`：`set_psw`/`set_psw1` 写同一组
`flag_c/flag_ac/flag_ov/reg_bank` 物理标志）：

- **C/AC/OV/RS 是 PSW 与 PSW1 两个视图共享的同一物理标志**。夹具的写入顺序固定为
  先 PSW 后 PSW1，因此**后写的 PSW1 会覆盖先写 PSW 的相应位**（combo4 的 AC、
  combo7 的 RS 因此回读为 0——这是共享语义的正常结果，不是写路径缺陷）。
- **N/Z 只存在于 PSW1**；写 PSW 不碰 N/Z。**F0/F1/P 只存在于 PSW**；写 PSW1 不碰 F0/F1。
- 读 PSW 时 **P 位由 ACC 奇偶即时计算**（夹具在该点 A=w-PSW1，P=popcount(w-PSW1)&1）。
- **DJNZ 对 N/Z 的行为是本实验被测项，判读按两种语义各给一支（§2.2），不得混用**：
  - **模型实测语义**（下文预期表的推导基准）：`DJNZ 每拍都写 N/Z`（终拍 0x23 减到
    0 → **Z=1、N=0**，其余位不动）；窗口开启指令 `orl 0x88,#0x10` 按结果写 N/Z
    （0x10 → N=0、Z=0）——I 阶段已在开窗后**重新建立 combo**，使非零 N/Z 存活到
    受理时刻（见 §3 修订记录）。
  - **经典 8051 语义（备择假设 H-A）**：DJNZ 与逻辑指令完全不动标志。此时写入的
    N/Z 没有任何机制清除，L 阶段的负向判据是 **af == bf 完整保持**——每个 combo
    的 after 逐位等于自己的 before/回读值（combo0 保持 00、combo1 保持 02、
    combo2 保持 20），而不是"af 归零"：写入的 02/20 在经典语义下本来就该原样
    保持。
- 受理时刻 PSW1 整体压入 4 字节硬件帧，`reti` 弹出并写回（`set_psw1`，同时覆盖
  C/AC/OV/RS/N/Z 共享位）；PSW 不在帧内，compiler 臂靠 `push psw`/`pop psw` 恢复。

**判读总规则**：逐行先与下文逐 combo 预测比对；**凡是偏离预测的行一律先进"专项排查"
（按 §4 回传全量数据，用 W/L/I 三阶段交叉定位），不得按单行现象直接归因硬件缺陷**。
H-A~H-D 只在 §2 各自指定的单一证据成立时引用，不再作为"rb≠w 之类"的兜底标签。

## 1. 行格式与字段

```text
V1P stage=W combo=NN w=PP/QQ rb=RR/SS
V1P stage=L combo=NN w=PP/QQ bf=RR/SS af=TT/UU
V1P stage=I combo=NN w=PP/QQ bf=RR/SS en=TT/UU af=VV/WW
V1P value=VV count=CC            （仅 r 模式；af-PSW1 直方图非零项）
```

| 字段 | 含义 |
|---|---|
| `w` | 本 combo 写入的 PSW/PSW1 立即数（C 侧记录） |
| `rb` | W 阶段：写入后立即回读的 PSW/PSW1 |
| `bf` | L/I 阶段：写入后、窗口前的快照（I 阶段采样在开窗 `orl` 之前） |
| `en` | I 阶段：ISR 在中断受理瞬间补记的 PSW/PSW1（仅 minisr 臂非零；compiler 臂恒 00/00，baseline 无 I 阶段） |
| `af` | L/I 阶段：RETI/等待结束后的 PSW/PSW1 |

combo 位含义（模型位序；硅片位序正是被测项）：
`1`=Z(PSW1.1)、`2`=N(PSW1.5)、`3`=C(经 PSW1.7)、`4`=AC(PSW.6)、`5`=F0(PSW.5)、
`6`=OV(两视图共享)、`7`=RS1(PSW.4，寄存器组选择)。

## 2. 逐阶段判读

### 2.1 W 阶段（写-读一致性，无中断）

共享语义逐 combo 预测（`rb-PSW1 == w-PSW1` 恒成立；`rb-PSW` 的 C/AC/RS/OV 来自
w-PSW1、F0 来自 w-PSW、P=popcount(w-PSW1)&1）：

| combo | w | rb 预测 | 备注 |
|---|---|---|---|
| 0 | 00/00 | **00/00** | 全零基线 |
| 1 | 00/02 | **01/02** | rb-PSW 的 01 是 P 位（A=0x02 奇校验），不是写入位 |
| 2 | 00/20 | **01/20** | 同上；rb-PSW1=20 证明 0x20 可写可读（N 位单元） |
| 3 | 00/80 | **81/80** | C 经 PSW1.7 写入、两视图都读回（81=C+P） |
| 4 | 40/00 | **00/00** | PSW 先写的 AC 被后写 PSW1=00 **按共享语义合法覆盖** |
| 5 | 20/00 | **20/00** | F0 只在 PSW，不被 PSW1 写覆盖 |
| 6 | 04/04 | **05/04** | OV 双视图写同一位（05=OV+P） |
| 7 | 08/00 | **00/00** | RS 同 combo4：被后写 PSW1=00 合法覆盖 |

| 观察 | 结论 | 动作 |
|---|---|---|
| 全部 combo 与上表一致（QEMU 2026-09-10 实测一致，见 §3） | 写路径与两视图共享语义在硅片上成立 → 后续判读有效 | 继续 |
| 某 combo `rb-PSW1 != w-PSW1` | H-D：PSW1 写路径/位序与假设不符 | 专项排查：逐位写读比对得出真实位序后重排本表 |
| combo3/4/7 的 `rb-PSW` 呈 01/40/08（C/AC/RS 未被 PSW1 写覆盖） | 硅片两视图物理独立（非共享）——**模型-硅片语义差异证据**，不是缺陷；L/I 阶段 C/AC/OV 预期改按独立视图推导 | 专项排查：按独立视图重推 L/I 预期后继续 |
| 其余任何偏离 | 未建模的读路径行为（如 P 位定义不同、F0 被覆盖等） | 专项排查 |

### 2.2 L 阶段（T10 同形等待循环自身污染对照，无中断）

`bf` 预测 == §2.1 的 `rb`。下表的 `af` 预测按**模型语义**推导：DJNZ 每拍写 N/Z，
终拍 `djnz 0x23` 减到 0 → **Z=1、N=0**，且 DJNZ 不动 C/AC/OV/RS/F0，故：

| combo | af 预测 | 备注 |
|---|---|---|
| 0 | **00/02** | 02 = DJNZ 终态 Z |
| 1 | **01/02** | Z=1 本就成立；P=1 |
| 2 | **01/02** | **N 被终拍 Z 覆盖（N=0）**——不是泄漏 |
| 3 | **81/82** | 82 = C(共享存活)+Z |
| 4 | **00/02** | |
| 5 | **20/02** | F0 存活 |
| 6 | **05/06** | 06 = OV(共享存活)+Z |
| 7 | **00/02** | |

经典语义分支（H-A）的预测只有一条，且对每个 combo 都成立：**af == bf 完整保持**
——PSW/PSW1 每一位逐位等于写入值/回读值（combo0 保持 00、combo1 保持 02、
combo2 保持 20、combo3 保持 81/80、combo5 保持 20/00、combo6 保持 05/04），
`r` 直方图呈保持值分布。判据依据见 §0 的双分支基准。

`r` 模式（写 00/00 后连跑 128 次）模型语义分支预测 **128/128 全部 `value=02
count=80`**（count 为十六进制，0x80=128；经典语义分支则为全部 `value=00`）。

| 观察 | 结论 |
|---|---|
| 全部 combo 与上表一致（模型语义分支）且 `r` 128/128 → 02 | 硅片 DJNZ 与模型同样写 N/Z 且终态确定 → T10 的 0x20 更可能是"受理相位落在 DJNZ 置 N 拍 + 帧恢复"（H-A 的 DJNZ 分支否定） |
| **af == bf 完整保持**：每个 combo 的 after 逐位等于 before/回读值（combo0→00、combo1→02、combo2→20，写入的 Z/N 原样存活，无 DJNZ 终态 Z），`r` 直方图呈对应保持值分布 | H-A：硅片 DJNZ 为经典语义（不动 N/Z，也不动 C/AC/OV/RS/F0）→ DJNZ 不是 0x20 来源；0x20 须由帧不恢复（H-B，见 §2.3）或 ISR 体内指令解释。注意判据是**完整保持**，不是"af 归零"——把 combo1/2 的 02/20 保持误读成异常，就看不见这一支 |
| 02/00 混合分布 | DJNZ 写 N/Z 但受理相位相关（把分布与计数原样回传）→ 专项排查 |
| 其它位偏离（如 82/06 未出现） | C/OV 共享存活假设不成立 → 结合 §2.1 combo3/6 回读值定位，专项排查 |

### 2.3 I 阶段（中断窗口，minisr 臂）

判读主键：**`af-PSW1 == en-PSW1 == w-PSW1`，且 combo1/2 的 `en-PSW1`=02/20 非零**。
非零 N/Z 建立点已移到开窗 `orl 0x88,#0x10` 之后（§3 修订记录），受理时刻的 PSW1
就是 combo 值本身；minisr 体内 `0x7f+0x01` 把 A 变 0x80 并置 N/AC/OV，RETI 后 `af`
采样。`bf` 预测 == §2.1 的 `rb`，`en` 预测 == `bf`：

**en 判定的前提（2026-09-10 第三轮起为构造保证）**：`_v1_ix` 每轮在开窗前显式重置
定时器——`mov 0x88,#0` 停表并清残留 TF0（撤掉可能挂起的旧请求）、`mov 0x89,#0x01`
强制十六位模式、`mov 0x8a/#0x8c` 把 TH0:TL0 重装为 0000，然后才 `orl 0x88,#0x10`
（TR0=1）。首次溢出距 TR0 置位**恒为 65536 个定时器时钟**，比建立 combo 的十余条
指令大三个数量级，"受理落在重建完成之后"由此成为构造保证而非状态巧合。因此本固件
上 en==w 是确定性预期；**未做该显式初始化的旧固件只有当次运行 en==w 的试次可用，
不能无条件推广**。实板若见 `en != w`（含 =00），**一律先按"受理过早（在 combo 重建
完成前受理）/开窗状态不符"处理**，专项排查（受理时序比对）优先于任何标志/帧语义
归因。

| combo | en 预测 | af 预测 | 备注 |
|---|---|---|---|
| 0 | **00/00** | **01/00** | af-PSW 的 01 来自 minisr 后 A=0x80 的 P 位 |
| 1 | **01/02** | **01/02** | **非零 Z 进帧并原样恢复——帧保存/恢复 PSW1 的直接证据** |
| 2 | **01/20** | **01/20** | **非零 N 进帧并原样恢复**（T10 的 0x20 场景的确定性复现） |
| 3 | **81/80** | **81/80** | C=80 进帧恢复 |
| 4 | **00/00** | **01/00** | AC 已被共享覆盖，无位可测（见 §2.1 combo4） |
| 5 | **20/00** | **21/00** | F0=20 不经帧、由 minisr 不保存而泄漏（预期）；21=F0+P |
| 6 | **05/04** | **05/04** | OV=04 进帧恢复 |
| 7 | **00/00** | **01/00** | RS 已被共享覆盖（见 §2.1 combo7） |

| 观察（minisr 臂） | 结论 | 对 T10 的 0x20 |
|---|---|---|
| 每个 combo `af-PSW1 == en-PSW1 == w-PSW1`（含 combo1→02、combo2→20） | **帧保存并恢复实测覆盖的 PSW1 位及其组合：N、Z、C（经 PSW1.7）、OV**——这是本夹具实际建立并验证的范围。**AC/RS 本轮仅零值覆盖**（combo4/7 的 w-PSW1=00，且共享语义本就把它覆盖为零，见 §2.1），其非零值经帧的行为**待后续 combo，不在本结论内** | 0x20 = 受理时刻 PSW1（等待循环相位），行为正确，T10 判读改写为"帧工作正常，采样点不严格" |
| 某 combo `en-PSW1 != w-PSW1`（含 combo1/2 的 `en-PSW1`=00） | **首先按"受理过早（在 combo 重建完成前受理）/开窗状态不符"处理**，不直接归因窗口内存在未建模的 N/Z 改写——后者只有在受理时序可证落在重建点之后时才成立 | 专项排查：回传反汇编比对 `_v1_ix` 建立点与受理时序，并确认开窗前定时器已显式重置（见上文 en 判定前提）；时序排除后才考虑标志侧解释 |
| 某 combo `en-PSW1 != 00` 但 `af-PSW1 == 00` | H-B：RETI 不把第 4 帧字节恢复进 PSW1；T10 的 0x20 若成立则须另有来源（帧保存但不恢复，体内泄漏被 RETI 清零） | 0x20 是保存/恢复缺陷的表现，向帧语义追责 |
| 某 combo `af-PSW1` 非零但 != `en-PSW1` | 恢复路径部分生效或位序不同（H-C 类） | 专项排查：结合 W 阶段位序结论与 minisr 的 add（模型置 N=1）交叉定位 |
| `af-PSW` 出现预测外的 AC/OV（0x44） | minisr 的 add 置 AC/OV 且 PSW 无硬件保护——**预期泄漏**方向；若 RETI 未清共享位则另有问题 | 专项排查 |

### 2.4 compiler 臂对照（其余条件一致）

compiler 臂 `en` 恒 00/00（T10 ISR 不补记入口值）。37 字节保存集不含 PSW1，
N/Z 只能由硬件帧保护；PSW 由 `push psw`/`pop psw` 恢复：

| 观察（compiler 臂） | 结论 |
|---|---|
| 每个 combo `af-PSW1 == w-PSW1`（combo1→02、combo2→20、combo3→80、combo6→04；QEMU 2026-09-10 实测一致） | 与 minisr 臂互为印证：帧恢复成立（范围同 §2.3 的限定：实测覆盖位 N/Z/C/OV；AC/RS 仅零值），且**不依赖 minisr 的手写补记** |
| combo5 的 `af-PSW` 含 0x20（F0 经 `pop psw` 恢复） | PSW 专属位走编译器保存集，与帧判读隔离，作对照 |
| `af-PSW` 的 P 位 | 随 ISR 体内 ACC 奇偶变化，**不作判读键** |
| minisr 臂显示恢复、compiler 臂某 combo `af-PSW1 != w-PSW1` | 编译器 ISR 序言/尾声与帧交互异常（如 pop psw 顺序问题）→ 属编译器缺陷证据 |
| 两臂 `af-PSW1` 均未恢复（且 minisr `en != af`） | H-B：帧不恢复，与编译器无关 |

### 2.5 `r` 模式补充

`value=02 count=80`（QEMU）读法：count 为十六进制，0x80=128 次。实板回传时请保留
全部非零行与重复次数；分布与 §2.2 的判读行对应。

   判据改为 **af == bf 逐 combo 完整保持**（combo0→00、combo1→02、combo2→20，
   逐位等于 §2.1 回读值），`r` 直方图按保持值分布判读。
2. **"帧恢复 PSW1 全部位"收窄为实测覆盖范围（§2.3/§2.4）**：本夹具实际建立并
   验证的是 N、Z、C（经 PSW1.7）、OV 及其组合；AC/RS 仅零值覆盖（combo4/7 的
   w-PSW1=00，且共享语义本就把它覆盖为零），其非零经帧行为待后续 combo，
   不在"帧恢复成立"的结论内。
3. **开窗时序固化为构造保证（gen-v1.py + check.py + §2.3）**：`_v1_ix` 每轮开窗前
   显式重置定时器（`mov 0x88,#0` 停表并清残留 TF0/挂起请求、`mov 0x89,#0x01`
   十六位模式、`mov 0x8a/#0x8c` 重装 TH0:TL0=0000），首次溢出距 TR0 置位恒为
   65536 个定时器时钟，"受理落在 combo 重建之后"不再依赖上一阶段遗留的定时器
   状态；check.py 新增对应静态断言（重装/清 pending 序列存在且先于开窗 orl）。
   §2.3 写明 en 判定前提：显式初始化后 en==w 为确定性预期；未初始化的旧固件仅
   当次运行有效；`en != w` 一律先按"受理过早/开窗状态不符"处理，专项排查优先于
   任何标志/帧语义归因（不再直接归因未建模的清标志指令）。
   复跑（见上文第三轮）确认时序固化前后行为逐位一致。
